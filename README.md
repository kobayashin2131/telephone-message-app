# 📞 CallSync（コールシンク）- 社内チャット ✕ 電話連絡DX統合SaaS

Google Chat（無料版）の置き換えと社内電話連絡DXを統合した、完全クローズドな次世代社内コミュニケーション基盤です。

---

## 🌟 実装済み機能

### 1. 💬 Google Chat / LINE風 クローズド社内チャット
- **1 on 1（個人DM）**: 社員同士のリアルタイムチャット
- **👥 都度グループ作成**:
  - **ハイブリッド選択UI**: 「営業部 全員」「総務部 全員」などの部門単位一括選択と、個別メンバー選択を組み合わせて即座にグループ作成
  - カスタムアイコン（🚀, 🚨, 💡, 🛠 など）と説明設定
- **🏢 部門公式チャンネル**: 各部署ごとの全体連絡ライン
- **👁 既読確認システム**:
  - 1on1：LINEのような「既読 / 未読」表示
  - グループ：Google Chat風の「既読 ○人（クリックで誰が何時に読んだか一覧ポップアップ）」
- **スレッド返信**: メッセージや受電カードごとにスレッドで会話を整理

### 2. 📞 受電メモ ✕ チャットカード統合（コア機能）
- **ワンクリック受電登録**:
  - 宛先（個人DM / グループ / 部門）へリッチな受電カードを即時投稿
  - 🚨 緊急受電 / 📞 折り返し希望 / ℹ️ 伝言のみ のバッジ自動色分け
- **インタラクティブステータス更新**:
  - カード上の「⏳ 対応中にする」「✓ 完了にする」ボタンでステータス変更＆対応メモ記録
  - 電話番号タップで即座に発信連携（`tel:`リンク）
  - 受電カードのスレッド内で「折り返しました」「追加で連絡ありました」を会話完結

### 3. 📇 受電先・顧客リスト（CRM連携プレビュー）
- よくかかってくる会社名・担当者・電話番号・定番用件をリスト登録・蓄積
- 受電登録時のインクリメンタルサジェスト・自動補完入力
- 過去受電回数や最終受電日時の記録

### 4. ⚙️ 管理者メニュー（組織・アカウント管理）
- 個人アカウント制（ログインユーザーのワンクリック切り替え可能）
- 部門マスタの自由追加・編集・削除
- 社員アカウントの追加・所属部門変更・管理者(Admin)権限設定

## 🚀 起動方法

### 簡単起動（おすすめ）
フォルダ内の `アプリ起動.bat` をダブルクリックするだけです。
バックエンド（Port: 3001）とフロントエンド（Port: 5173）が自動起動し、ブラウザが開きます。

### コマンドラインでの起動
```bash
# 1. バックエンド起動
cd backend
node index.js

# 2. フロントエンド起動（別ターミナル）
cd frontend
npm.cmd run dev
```
ブラウザで `http://localhost:5173` にアクセスしてください。
